For a social livestream, capture this studio window in OBS Studio, add desktop audio, then connect OBS to the selected streaming platform using its stream key. For multistreaming, use a compatible RTMP relay service.

Important: Browser guest calls are real-time WebRTC, but this starter does not directly publish RTMP or implement social OAuth. Never enter your social stream keys in the public guest studio.
